Kommunikation direkt aus dem Graphen

Erklärungen über den Deutschland-Stack (wie bspw. ein Steckbrief oder eine Textpassage) werden heute getrennt vom Modell gepflegt. Sie veralten, sobald sich eine Zahl ändert, und niemand sieht ihnen an, woher sie stammen. Hängt man sie stattdessen direkt an den Graphen, werden »Kommunikationsstücke« zur Projektion des Graphen.

1. Automatischer Steckbrief zu einer Leistung

Aus dem Graphen ließen sich bspw. Steckbriefe zur D-Stack-Abdeckung in Verwaltungsleistungen für ein gewünschtes Zielpublikum generieren. Die Leistungen hier im Beispiel stammen aus dem Portalverbund Online-Gateway (PVOG); erfunden ist nur die Zuordnung, welche Bausteine hinter einer Leistung stehen. Technisch zeigt die technischen Beschreibungen aus der offiziellen Landkarte, fachlich beispielhaft verfasste Texte. Beide hängen am selben Knoten, sodass die Texte nie auseinanderlaufen.

2. Was alles an einem Baustein hängt

Hier soll verdeutlicht werden, warum sich ein gemeinsames Modell aus Komms-Perspektive lohnt: Wähle einen Baustein des D-Stack und automatisch wird berichtet, was alles an ihm hängt, quer durch die Schichten. Jede Zahl stammt aus einer anderen Datenquelle (PVOG, FIT-Connect, die fiktive Kommune Musterstadt und deren hypothetisches Vorhaben). So ließe sich etwa auf einen Blick abschätzen, wen eine Änderung an diesem Baustein berühren würde.

3. Textvorlagen, live aus dem Graphen befüllt

Derselbe Deutschland-Stack, vier beispielhafte Perspektiven. Jede ist eine vorgefertigte Textvorlage mit Platzhaltern für die Zahlen. Wird eine ausgewählt, werden die Platzhalter mit aktuellen Zahlen aus dem Graphen gefüllt.

Jede Vorlage bringt dabei die Abfrage, die ihre Zahlen besorgt, selbst mit. Sie liegt nicht versteckt im Programm, sondern steckt direkt im Graphen. So bleibt die Aussage aktuell, und über die verlinkte Abfrage sind die Zahlen nachprüfbar.
